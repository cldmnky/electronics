# Open Source Hardware gear artwork

`oshw-logo-filled-black.svg` is the official Open Source Hardware logo artwork
by **Macklin Chaffee**, downloaded from
<https://oshwa.org/resources/open-source-hardware-logo/> (source:
<https://resources.oshwa.org/files/assets/oshw-logo-filled-black.svg>).
OSHWA describes the gear logo as **CC-SA**. The generated gear-only outline
`../tscircuit/lib/oshw-outline.ts` and its scanline silkscreen adaptation are derived
from that artwork and are offered under the same share-alike terms. The SVG is
retained here for provenance and modification; the rest of this repository's
license is not a replacement for the artwork's terms.

The gear is the community open-hardware logo, **not** an OSHWA certification
mark or a claim of certification. OSHWA says it may be used if the hardware
complies with the Open Source Hardware Definition; the project owner must confirm
that compliance, including the availability of the complete design materials,
before distributing boards with the logo.
