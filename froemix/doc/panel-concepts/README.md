# Front-panel concept studies

These HTML bundles are visual studies, **not manufacturing files**. Unzip each
bundle and open `index.html` to compare the bare panel and illustrative assembled
hardware. The manufactured graphic is white ink only; hardware shading, LED glow
and an OLED image are preview effects.

- **Nord / Studio:** restrained instrument styling; recommended starting point.
- **Signal / Field:** bolder output rings, group brackets and a waveform motif.

The owner has not selected a direction yet. They share the existing mechanical
layout. Editable canvas tweaks in a study do not change the tscircuit source or
validate clearances; do not submit an HTML/SVG screenshot as a fabrication file.
Use the checked manufacturing exports described in [FRONT-PANEL.md](../FRONT-PANEL.md).

The production source uses rounded OLED corners and tested single-stroke paths.
A concept may show idealised corners or browser-font lettering. The generated
production preview, rather than this study, is the reference for the released
silkscreen geometry.
