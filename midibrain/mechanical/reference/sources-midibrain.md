# Primary manufacturer sources — Midibrain printed parts and their switches

Register of the manufacturer documents this review relied on, with the URL, the
SHA-256 of the copy that was read, the retrieval date and the values quoted from
it. **No vendor PDF is committed**: only the reference and the numbers read out of
it. A hash here identifies the file that was read; it is not a licence to
redistribute it.

Rules that apply to every row:

* A quoted value is a **drawing/datasheet value**, never a measurement of a
  supplied part.
* Where a page does not print a dimension, the row says so. Nothing is
  interpolated, and no value is copied from one page or one variant to another.
* Everything here still needs the first-article measurement listed in
  `docs/acceptance.md`; the two lists are different kinds of evidence.

## How these sources are used

* `tscircuit/lib/layout.ts` carries the values that drive geometry, each with the
  source named beside it; `mechanical/layout.json` is generated from it.
* `mechanical/printed/printed_geometry.py` carries the datasheet constants and
  refuses to build when `lib/layout.ts` disagrees with them.
* `mechanical/printed/nav_fit.py` takes every unmeasured number as a **range**.
* A source value never becomes evidence: `docs/acceptance.md`
  (`hardware-acceptance.json`) lists the physical items that only a measurement
  can close, and this review leaves all 31 of them pending.
